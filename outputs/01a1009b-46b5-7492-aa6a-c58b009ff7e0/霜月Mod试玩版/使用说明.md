# 霜月 Frostmoon v0.2.0 试玩版

面向《杀戮尖塔 2》v0.107.1 的原创角色 Mod。当前在 macOS Apple Silicon 的真实游戏中构建、加载和测试；Windows 的 DLL 通用，但尚未实机验证。

## 快速体验

本机优先双击交付目录中的「启动霜月隔离试玩.command」。它打开独立的游戏副本，使用 FrostmoonIsolatedPlaytest 数据目录，并将存档操作绑定到本地测试存储。需要 Steam 已经运行、且账号拥有游戏。

试玩不需要额外安装 .NET SDK 或 Godot 编辑器。独立试玩入口只适用于本机交付目录；把 ZIP 发到其他电脑时，使用下面的常规 Mod 安装方式。

进入「单人游戏 → 标准模式」，选择霜月。主菜单的 Mod 设置里可以选择起始牌组：

| 数值 | 牌组 | 用途 |
|---|---|---|
| 0 | 标准 10 张 | 正常爬塔、考察前期强度 |
| 1 | 冰月往复 20 张 | 首先体验形态切换与月蚀 |
| 2 | 极霜守夜 20 张 | 霜资源与格挡 |
| 3 | 月蚀潮汐 20 张 | 月痕、月蚀与能力联动 |
| 4 | 血月回潮 20 张 | 扣血、回收与血月窗口 |

设置只影响新开局。四套测试牌组均为原设计样例，包含指定升级，无稀有牌。修改设置后再创建新的对局。建议先用牌组 1。

## 正式游戏安装

压缩包中的 `mods/BaseLib` 与 `mods/Frostmoon` 放入游戏的 `mods` 文件夹。macOS 的目录为 `SlayTheSpire2.app/Contents/MacOS/mods`；Windows 位于游戏可执行文件旁。重新启动游戏，首次加载 Mod 时按游戏提示启用。

本地已安装 STS2AIMCP 的环境可并存，但首轮验证只加载 BaseLib 和 Frostmoon。不要在正在进行的旧对局上测试新卡池；先完成旧局，或使用独立试玩入口。

卸载时关闭游戏并移走 `mods/Frostmoon`。BaseLib 是通用依赖，其他 Mod 可能需要它；无需一起删除。包含霜月的进行中对局需要该 Mod 才能继续。

## 实装内容

- 72 生命、3 能量；64 张主卡及其升级，2 张衍生牌；双相佩初始遗物。
- 冰：每回合前 2 张以冰开始结算的技能各得 1 霜；本回合首次在冰触发月蚀后回生 2。
- 月：每回合前 2 张以月开始结算的单体攻击，额外支付 1 生命，随后附加 1 月痕；若支付 1 霜则附加 2。主成本和额外成本无法安全合付时跳过这次月被动。多段攻击仅支付一次。
- 霜默认上限 6。敌人每满 8 月痕，扣去 8 并触发月蚀：4 次 4 点效果伤害，保留余层。神器可阻挡施加，月蚀不享受力量和易伤等攻击修正。
- 生命不高于最大生命的 40% 时，在自身回合开始或完整卡牌结算后进入血月；触发它的牌不追溯翻倍。血月使攻击和月蚀伤害翻倍，不额外给能量或抽牌。
- 血月当回合结束返回冰；也能主动提前退出。下个自身回合抽牌后生成「余烬覆雪」。下一整个自身回合不能再次触发；血月外恢复到至少 55% 才能重新准备。
- 主动支付生命形成「回生储备」。回生只收回这部分，不能抹去敌人造成的伤害；真正治疗同时先扣除储备，防止重复回收。
- 战斗上方显示形态、霜、回生储备、血月阈值和冷却。悬停状态或卡牌可查看说明。

## 美术与当前边界

白色短发、太刀、黑白服装的日漫风成年女性角色，已接入战斗、选择背景、商店和休息场景。战斗采用静态立绘的轻量位移动画。攻击／技能／能力暂用三类符号卡图；音效、能量面板与部分小图标沿用本体资源。本版优先验证机制，不代表最终美术。

已做本地单人验证；多人、所有原版遗物组合、完整高进阶通关与跨平台环境尚未覆盖。测试牌组并非平衡性结论。战斗内状态遵循本体的战斗重载方式，不额外保存中途快照。回生储备当前以数字呈现，尚未添加灰色生命条。

## 源码与调整

- `src/Cards.cs`：所有卡牌行为；`src/State.cs`：三形态、资源、月蚀、回血与能力联动。
- `src/Character.cs`：角色、初始遗物、卡池与战斗 UI。
- `src/Catalog.g.cs`：可独立构建的卡牌定义与注册，由 `tools/generate_cards.py` 生成。
- `src/PlaytestConfig.cs`：测试牌组入口；`src/EngineTests.cs`：显式启动的引擎测试。
- `assets/`：打包资源；`art/`：原始生成立绘与来源说明。

修改数值时，需要同时修改行为参数和对应卡文；Excel 不是当前运行时数据源。基础伤害／格挡映射位于生成脚本，其他效果参数位于 Cards.cs 和 State.cs。

使用 .NET 9 SDK 编译：`dotnet build Frostmoon.csproj -c Release -p:GameDir=/游戏托管程序集目录`。依赖游戏合法安装中的 sts2.dll、GodotSharp.dll、0Harmony.dll，以及 BaseLib 3.3.0。源代码包和安装包不包含游戏本体代码、程序集或原版美术。

资源打包：`dotnet run --project tools/BuildPack -- assets dist/Frostmoon/Frostmoon.pck`。缺少本机构建工具缓存时，会通过 NuGet 取得固定版本的打包工具。
