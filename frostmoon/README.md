# 霜月 Frostmoon：Mod、研究与设计

当前实现为 [霜月 Mod v0.2.2 冰月绘卷](mod/README.md)，包含 64 张主卡、2 张衍生牌、三形态机制和独立插画。使用方式、构建依赖与验证边界以 Mod 说明为准。

本目录同时保留第一阶段的若叶睦完整卡池源码研究、卡池结构分析、15 张霜月原型牌，以及后续 [v0.2 设计数据](v02/design.json)与[状态规则](v02/rules.json)。以下原型文档是设计历史，不是当前运行时卡池。

- [若叶睦研究结论](研究结论.md)：固定源码版本、93个卡牌类、稀有度分工、桥梁与功能升级。
- [霜月原型规则](原型规则.md)：状态时序、15张牌分工、测试参数、四组测试牌组和边界用例。
- [完整卡牌数据](data/reference_cards.json)：逐牌基础效果、升级变化、构筑和设计职责及源码链接。
- [霜月参数与卡牌数据](data/prototype.json)：15张提案与数值起点。
- [可筛选研究工作簿](../outputs/01a1009b-46b5-7492-aa6a-c58b009ff7e0/霜月卡池研究与原型.xlsx)：摘要、原型牌、可调参数和完整参考清单。

源码事实与构筑解读分开。研究固定提交03dc9add4db955351e05bcfce06cf2889f25a695；清单覆盖全部93个卡牌类，其中85张是普通奖励稀有度，80张适用于单人。参考源码摘录的MIT声明保存在data/LICENSE-reference.txt。

第一阶段研究没有运行参考 Mod、进行战斗模拟或验证平衡。后续实现与本地测试记录见 [Mod 测试记录](mod/测试记录.txt)；尚未发布 Workshop。
